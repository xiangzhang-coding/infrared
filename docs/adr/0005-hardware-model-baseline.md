# 5. 硬件/模型基线：沿用学习站 ADR-0001，Qwen2.5 架构，0.5B 开发 / 7B 压测

- **Status（状态）**: Accepted
- **Date（日期）**: 2026-08-14

## Context（背景）

infrared 与学习站是同一学习者、同一预算。需要一个贯穿全阶梯的硬件/模型基线，否则各档各选卡选模型，示例数字与显存估算无法一致。且从零引擎必须自实现模型 forward，模型族的选择直接决定要写哪些结构（RoPE/GQA/…）。

## Decision（决策）

- **硬件/预算**：**沿用学习站 ADR-0001**——单张 RTX 4090(24G) via AutoDL、¥500 预算、非计算工作走**无卡模式**。
- **模型架构**：**自实现 Qwen2.5 dense**（RMSNorm/RoPE/GQA/SwiGLU），与学习站 7B 基线**同族**，GQA/KV 课全部可迁移、可对拍。
- **两档模型**：**正确性开发/对拍用 `Qwen2.5-0.5B-Instruct`**（CPU/Mac 可跑、迭代快、KV 极小）；**北极星压测用 `Qwen2.5-7B`**（延续学习站数字；FP16 ~15GB 权重 + KV 在 24GB 放得下）。
- **正确性对拍标尺**：**HF `transformers`** 既是权重来源、又是 forward 正确性 gate（同权重、greedy+seed 比对）。
- **多卡例外**：T6 的张量并行 (TP) 需 **临时租 2 卡机**（AutoDL 短开即关）验证——与「单 4090」基线的唯一例外，记于该档。

## Consequences（后果）

**正面：**
- 预算可控、显存/吞吐估算一致、读者可复现。
- 0.5B 让绝大多数引擎逻辑在本机 CPU 就能开发调试，GPU 只在压测时租，比学习站更省。

**权衡 / 负面：**
- 7B 单卡无法体验真实大集群 TP 规模——只小规模演示（继承学习站 ADR-0001 的取舍）。

**可逆性：** 中——模型与卡是配置项，预算放宽可上调；但阶梯表数字与显存估算围绕此基线，改动需整体重算，故立此 ADR。
